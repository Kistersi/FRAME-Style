# FRAME / STYLE – Phase 1

Responsive iPhone-first PWA im Dark-Cinematic-Design.

## Enthalten
- Startseite und Navigation: Home, Atelier, Galerie, Stile
- Fotoimport und Bildvorschau mit Pixelmaßen
- Auswahl der sieben Fotostile
- Auswahl Farbig / Schwarz-Weiß
- PWA-Manifest, Service Worker und App-Icon

## Noch nicht implementiert
Die Bildfilter, KI-Optimierung, Schärfung/Rauschreduzierung, Crop-Werkzeuge, Vorher-Nachher-Regler, dauerhafte Bildspeicherung und Hook-Generator folgen in späteren Phasen. Die Stil- und Farbwahl ist derzeit eine UI-Auswahl und verändert das Foto noch nicht.

## GitHub Pages
In Settings → Pages die Veröffentlichung über Branch `main` und Ordner `/ (root)` aktivieren. Danach die HTTPS-Adresse in Safari öffnen und über Teilen → Zum Home-Bildschirm hinzufügen installieren. Für PWA und Service Worker ist HTTPS erforderlich.
